# Website QA Checklist

## Content accuracy

- [ ] Business name, phone, email, address, hours, and service areas are correct.
- [ ] All services, prices, packages, menus, listings, and availability statements are accurate.
- [ ] All reviews and testimonials are genuine and approved.
- [ ] Licenses, insurance, certifications, awards, ratings, warranties, and experience claims are verified.
- [ ] Demo text, sample images, placeholder photos, and fake values are removed.
- [ ] Client has approved final copy and media.

## Navigation and links

- [ ] Header navigation works.
- [ ] Footer navigation works.
- [ ] All internal links work.
- [ ] External links open the correct destination.
- [ ] Phone links use the correct number.
- [ ] Email links use the correct public email.
- [ ] Maps, social, booking, payment, and review links work.
- [ ] 404 page works.

## Forms and conversion

- [ ] Correct form type is used for the client goal.
- [ ] Every field has a visible label.
- [ ] Required fields are clear.
- [ ] Invalid form input produces understandable feedback.
- [ ] Success message or thank-you path works.
- [ ] Form delivery is tested on production or preview environment.
- [ ] Lead reaches the intended inbox, CRM, or provider dashboard.
- [ ] Spam protection is enabled where appropriate.

## Responsive presentation

- [ ] Homepage works on phone, tablet, and desktop.
- [ ] Navigation works on small screens.
- [ ] Buttons have easy-to-tap size.
- [ ] No horizontal scrolling occurs.
- [ ] Text is readable at 200% zoom.
- [ ] Images crop appropriately.
- [ ] Sticky mobile CTA does not block form controls or important content.

## Accessibility baseline

- [ ] One clear H1 is present on each page.
- [ ] Heading order is logical.
- [ ] Keyboard focus is visible.
- [ ] Interactive controls work with keyboard.
- [ ] Informative images have useful alt text.
- [ ] Decorative images use empty alt text.
- [ ] Color is not the only way status or errors are communicated.
- [ ] Form labels and errors are understandable.

## Technical checks

- [ ] `npm run build` succeeds.
- [ ] Favicon loads.
- [ ] robots.txt is correct.
- [ ] Sitemap is configured if included.
- [ ] Canonical URLs are correct.
- [ ] Page titles and descriptions are unique and accurate.
- [ ] Open Graph preview image exists.
- [ ] HTTPS works.
- [ ] Analytics and Search Console are enabled only if agreed and client-owned.
