# Launch Checklist

## Business accuracy

- [ ] Business name, legal name, phone, email, address, hours, and service areas are correct.
- [ ] Client has approved all page copy, images, logos, services, pricing, credentials, and policies.
- [ ] All placeholders and demo content are removed.
- [ ] Testimonials are genuine and approved for publication.
- [ ] Ratings, guarantees, licenses, certifications, claims, and case studies are verified.

## Functionality

- [ ] Header, footer, buttons, and internal links work.
- [ ] Phone, email, map, social, booking, and payment links work.
- [ ] Every form delivers to the intended recipient.
- [ ] Form success and error states work.
- [ ] Mobile navigation works.
- [ ] FAQ and interactive controls work with keyboard.
- [ ] 404 page works.

## Presentation

- [ ] Site has been checked on phone, tablet, and desktop widths.
- [ ] Text is readable and buttons are easy to tap.
- [ ] There is no horizontal scrolling.
- [ ] Images are relevant, permitted, sized correctly, and include appropriate alt text.
- [ ] Color contrast is readable.

## Search and technical

- [ ] Each public page has an accurate title and description.
- [ ] Favicon is present.
- [ ] `robots.txt` is correct for the production domain.
- [ ] Sitemap is generated and submitted if agreed.
- [ ] HTTPS works.
- [ ] Root and www domain behavior is configured intentionally.
- [ ] Analytics and Search Console are client-owned and added only if agreed.
- [ ] `npm run build` succeeds before launch.

## Handoff

- [ ] Client receives account access according to the agreement.
- [ ] Client has the domain registrar and relevant service ownership.
- [ ] Client receives a clear maintenance/support contact process.
