# New Client Setup

## Before creating a project

- Confirm the website goal: calls, estimates, leads, bookings, sales, portfolio, or credibility.
- Confirm pages and features included in the written scope.
- Confirm who owns the domain, hosting, forms, booking system, CRM, analytics, and payment accounts.
- Confirm the client will provide accurate business information, images, reviews, and approvals.

## Create the client project

1. Duplicate the master library into a new private repository.
2. Use a clear repository name, such as `acme-plumbing-website`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Update `src/content/site.json`.
6. Update services, reviews, FAQs, service areas, and process data.
7. Replace every placeholder logo, image, review, and claim.
8. Update `src/styles/theme.css` for the brand.
9. Choose page recipes and components from `/library`.
10. Run `npm run build` before sharing any preview.

## Preview and launch

1. Push the client repository to GitHub.
2. Connect it to Cloudflare Pages.
3. Use `npm run build` as the build command.
4. Use `dist` as the build output directory.
5. Test the preview URL.
6. Gather feedback in one organized list.
7. Obtain written launch approval.
8. Connect the client domain.
9. Complete the launch checklist.
10. Provide client handoff details.
