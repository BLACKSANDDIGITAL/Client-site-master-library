# SEO Checklist

## Page metadata

- [ ] Every public page has a unique, accurate title.
- [ ] Every public page has a useful meta description.
- [ ] Each page has one clear H1.
- [ ] Headings describe the page content naturally.
- [ ] Canonical URL points to the correct production URL.
- [ ] Open Graph title, description, and image are accurate.
- [ ] Favicon is present.

## Content quality

- [ ] Services are described in clear, specific language.
- [ ] Local service areas are accurate.
- [ ] Testimonials and business proof are genuine.
- [ ] Content answers real visitor questions.
- [ ] Images have useful filenames and alt text where informative.
- [ ] No copied, low-value, keyword-stuffed, or thin location content is published.

## Technical basics

- [ ] robots.txt uses the real production sitemap URL.
- [ ] Sitemap is generated and submitted if in scope.
- [ ] HTTPS works on the production domain.
- [ ] Root and www domain behavior is intentional.
- [ ] Broken links are fixed.
- [ ] Pages load successfully on mobile.
- [ ] Important public pages are crawlable.

## Structured data

- [ ] LocalBusiness schema is used only for a genuine local or physical business.
- [ ] Business name, phone, email, address, service areas, and URLs are accurate.
- [ ] Organization schema is used instead if LocalBusiness is not appropriate.
- [ ] Service schema matches the visible individual service page.
- [ ] Breadcrumb schema matches visible breadcrumbs.
- [ ] Structured data is not used to make unsupported claims.

## Accounts

- [ ] Client owns or controls Search Console.
- [ ] Client approves analytics setup.
- [ ] Client-owned analytics identifier is used.
- [ ] Sitemap is submitted after launch if agreed.
