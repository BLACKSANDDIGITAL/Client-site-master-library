# Content Request List

Use this list to track what content the client needs to provide before the website can launch. Do not publish placeholder content.

## Required before first review

- [ ] Verified business name, phone, email, address, and hours
- [ ] Approved service or product descriptions
- [ ] Logo file (vector format preferred)
- [ ] Approved hero image (or confirmation that no image is available)
- [ ] Approved team member names, roles, and bios (if team page is included)
- [ ] Approved testimonials with attribution (if testimonials section is included)
- [ ] Approved FAQ questions and answers (if FAQ section is included)
- [ ] Approved service area information (if service area section is included)
- [ ] Approved pricing or confirmation to use "Contact for pricing"
- [ ] Form delivery recipient email or endpoint
- [ ] Privacy policy approval (or confirmation to use starter template)
- [ ] Terms of service approval (or confirmation to use starter template)

## Required before launch

- [ ] All placeholder text replaced with approved copy
- [ ] All demo images replaced with approved photography
- [ ] All reviews, ratings, and testimonials verified as genuine
- [ ] All credentials, licenses, and certifications verified
- [ ] Domain registrar access confirmed
- [ ] Cloudflare Pages or hosting access confirmed
- [ ] Analytics and Search Console accounts confirmed
- [ ] Form, booking, and payment integrations tested
- [ ] Written launch approval received

## Image requirements

- Format: JPG or PNG, WebP preferred
- Minimum dimensions: 1200px wide for hero images, 800px for cards
- File naming: descriptive, lowercase, hyphenated (e.g., `acme-team-photo.jpg`)
- Permissions: only use images the client owns, licenses, or has permission to publish
- Alt text: provide for informative images; decorative images use `alt=""`
